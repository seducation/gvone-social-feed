# Community Feed Reference Notes

## Horizontal source switcher

- The reference uses a dark rounded horizontal tray with spaced circular source icons.
- Each source is represented by an icon with a short, truncated label beneath it.
- The row extends beyond the viewport to imply horizontal scrolling rather than wrapping.
- A prominent circular plus action at the end adds a new source or category.
- The overlapping tile boundary repeats the ESPNcricinfo source, confirming one continuous left-to-right row.

## Community channel navigation

The upper reference establishes a dark community panel with a visual header, a large community title, muted membership metadata, and a full-width search control. Beneath a divider, the design introduces utility rows before grouping channels under concise section labels. Channel rows use small semantic icons, quiet secondary text, and clear vertical spacing; the overlap shows the search control continues directly into this hierarchy.

The lower reference uses expandable-looking section headings and distinguishes the selected channel with a broad, softly rounded dark-gray background. Announcement rows use a megaphone treatment and an optional unread badge, while regular channels use a hash-style marker. The overlap keeps the selected announcement continuous into lower categories, confirming the design should preserve a single, vertically ordered channel list on narrow screens.
